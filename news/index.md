- Parameter `keep` allows users to define which repositories should be
  archived ([\#13](https://github.com/ropensci-org/gitcellar/issues/13),

- The README and function documentation include a note about the
  required permissions for the GitHub PAT
  ([\#11](https://github.com/ropensci-org/gitcellar/issues/11),
  [@Bisaloo](https://github.com/Bisaloo))

- Asking for repositories from an external organization in `extra_repos`

  ([\#10](https://github.com/ropensci-org/gitcellar/issues/10),
  [@Bisaloo](https://github.com/Bisaloo))

- Fix GitHub PAT finding for the curl step
  ([\#6](https://github.com/ropensci-org/gitcellar/issues/6),
  [@k-doering-NOAA](https://github.com/k-doering-NOAA)).

- Added a `NEWS.md` file to track changes to the package.
